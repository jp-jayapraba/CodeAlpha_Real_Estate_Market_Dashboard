# CodeAlpha Real Estate Market Trends Dashboard

## Project Overview

This project is an interactive Real Estate Market Trends Dashboard developed using Microsoft Power BI for CodeAlpha Internship Task 3.

The dashboard analyzes property prices, rental yields, market demand and supply, economic indicators, and geographical property locations to support real estate market analysis.

## Objectives

- Analyze property prices across cities.
- Compare average property prices and rental yields.
- Track market demand and supply trends.
- Explore interest rates and unemployment rates over time.
- Visualize geographical property hotspots using latitude and longitude.

## Tools and Technologies

- Microsoft Power BI Desktop
- DAX
- Microsoft Excel

## Dashboard Features

### Key Performance Indicators
- Total Properties
- Average Property Price
- Average Monthly Rent
- Rental Yield

### Visualizations
- Average Property Price by City
- Rental Yield by City
- Market Demand vs Supply Trends
- Real Estate Market Hotspots Map
- Economic Indicators Over Time

## Dataset

The project uses sample data organized into two tables:

- **Properties:** Property ID, city, locality, property type, area, price, monthly rent, demand score, supply units, latitude, and longitude.
- **MarketTrends:** Monthly property prices, rent, demand and supply indices, interest rates, unemployment rates, and new listings.

The dataset is for practice and demonstration purposes; it is not official real estate market data.
